What you get

One desktop app for every coding agent you run, with the work around them in the same window.

  • Terminals and sessions

    Every agent runs in a real terminal, resumes after a restart, and every past session is one search away.

  • Code, changes and review

    An editor, git and diffs; note lines in a diff and send the notes to the agent in one message.

  • Pipelines

    Several agents, from different vendors if you like, work toward one goal in stages.

  • Privacy and your data

    One page lists every connection the app makes and every folder it touches, with a switch that turns its network calls off.

Every feature

Install in three steps

The builds are not signed yet, so macOS and Windows ask once on the first launch. That is expected: the third step says what to click, and the updates the app installs keep working after it.

macOS

  1. 1

    Download

    Choose the .dmg for your Mac: Apple silicon for the M chips, Intel for the older Macs. About This Mac names your chip.

  2. 2

    Install

    Open the .dmg and drag Skribly Agent to Applications.

  3. 3

    Open it once

    The app is not signed with an Apple Developer certificate yet, so macOS blocks the first launch. Open System Settings → Privacy & Security, scroll to the message about Skribly Agent and click Open Anyway. Or remove the quarantine flag in Terminal:

    xattr -dr com.apple.quarantine "/Applications/Skribly Agent.app"

You do this once. “Skribly Agent is damaged and can’t be opened” has the same cause and the same fix.

Windows

  1. 1

    Download

    Take the installer for x64 and ARM64: it picks the right one. The single-architecture installers are smaller, and the portable build needs no installation.

  2. 2

    Run anyway

    The installer is not code-signed yet, so SmartScreen may say “Windows protected your PC”. Click More info, then Run anyway.

  3. 3

    Install

    Choose the folder and whether to install for yourself or for all users.

The portable build runs without installation and does not update itself.

Linux

  1. 1

    Download

    The AppImage runs on any x64 distribution. The .deb and .rpm packages add Skribly to the application menu.

  2. 2

    Install

    Make the AppImage executable and run it, or install a package: sudo apt install ./Skribly-linux-amd64.deb on Debian and Ubuntu, sudo dnf install ./Skribly-linux-x86_64.rpm on Fedora, RHEL and openSUSE.

    chmod +x Skribly-linux-x86_64.AppImage && ./Skribly-linux-x86_64.AppImage
  3. 3

    FUSE 2

    On a system without FUSE 2, install libfuse2 (libfuse2t64 on Ubuntu 24.04) or run the AppImage with --appimage-extract-and-run.

The AppImage updates itself; the .deb and .rpm packages are updated by installing the new version.

Check a download

Every release has a SHA256SUMS.txt beside its files. In the folder of the download, run:

shasum -a 256 -c SHA256SUMS.txt --ignore-missing
sha256sum -c SHA256SUMS.txt --ignore-missing

Updates

The app checks for updates and installs them on restart: the installer on Windows, the AppImage on Linux and the .zip package on macOS. The .deb, .rpm and portable builds are updated by installing the new version.

System requirements

macOS
macOS 12 or later, Apple silicon or Intel.
Windows
Windows 10 or 11, x64 or ARM64.
Linux
x64, as an AppImage, a .deb or an .rpm package.
git
git in your PATH.
An agent
At least one coding agent, for example npm install -g @anthropic-ai/claude-code.
No Node.js
No separate Node.js: the app runs its helpers with its own runtime.
ssh
OpenSSH only when you run agents on remote machines.
