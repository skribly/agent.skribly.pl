Co dostajesz

Jedna aplikacja na komputer dla wszystkich agentów programujących, których używasz, z pracą wokół nich w tym samym oknie.

  • Terminale i sesje

    Każdy agent działa w prawdziwym terminalu, wznawia pracę po restarcie, a każda dawna sesja jest o jedno wyszukiwanie stąd.

  • Kod, zmiany i przegląd

    Edytor, git i diffy; notatki przy wierszach diffu i wysyłanie ich agentowi w jednej wiadomości.

  • Potoki

    Kilku agentów, także różnych dostawców, pracuje etapami nad jednym celem.

  • Prywatność i Twoje dane

    Jedna strona wypisuje każde połączenie, które nawiązuje aplikacja, i każdy folder, którego dotyka, z przełącznikiem wyłączającym jej połączenia sieciowe.

Wszystkie funkcje

Instalacja w trzech krokach

Wersje nie są jeszcze podpisane, więc macOS i Windows pytają raz, przy pierwszym uruchomieniu. Tak ma być: trzeci krok mówi, co kliknąć, a aktualizacje instalowane przez aplikację działają potem dalej.

macOS

  1. 1

    Pobierz

    Wybierz .dmg dla swojego Maca: Apple Silicon dla układów M, Intel dla starszych Maców. Ten Mac (About This Mac) pokazuje Twój układ.

  2. 2

    Zainstaluj

    Otwórz .dmg i przeciągnij Skribly Agent do Applications.

  3. 3

    Otwórz raz

    Aplikacja nie jest jeszcze podpisana certyfikatem Apple Developer, więc macOS blokuje pierwsze uruchomienie. Otwórz System Settings → Privacy & Security, przewiń do komunikatu o Skribly Agent i kliknij Open Anyway. Albo usuń flagę kwarantanny w Terminalu:

    xattr -dr com.apple.quarantine "/Applications/Skribly Agent.app"

Robisz to raz. Komunikat „Skribly Agent is damaged and can’t be opened” ma tę samą przyczynę i to samo rozwiązanie.

Windows

  1. 1

    Pobierz

    Weź instalator dla x64 i ARM64: sam wybiera właściwą wersję. Instalatory dla jednej architektury są mniejsze, a wersja przenośna nie wymaga instalacji.

  2. 2

    Uruchom mimo to

    Instalator nie jest jeszcze podpisany, więc SmartScreen może pokazać „Windows protected your PC”. Kliknij More info, potem Run anyway.

  3. 3

    Zainstaluj

    Wybierz folder oraz instalację dla siebie lub dla wszystkich użytkowników.

Wersja przenośna działa bez instalacji i nie aktualizuje się samodzielnie.

Linux

  1. 1

    Pobierz

    AppImage działa w każdej dystrybucji x64. Pakiety .deb i .rpm dodają Skribly do menu aplikacji.

  2. 2

    Zainstaluj

    Nadaj AppImage uprawnienia do wykonywania i uruchom go albo zainstaluj pakiet: sudo apt install ./Skribly-linux-amd64.deb w Debianie i Ubuntu, sudo dnf install ./Skribly-linux-x86_64.rpm w Fedorze, RHEL i openSUSE.

    chmod +x Skribly-linux-x86_64.AppImage && ./Skribly-linux-x86_64.AppImage
  3. 3

    FUSE 2

    W systemie bez FUSE 2 zainstaluj libfuse2 (libfuse2t64 w Ubuntu 24.04) albo uruchom AppImage z opcją --appimage-extract-and-run.

AppImage aktualizuje się sam; pakiety .deb i .rpm aktualizujesz, instalując nową wersję.

Sprawdź pobrany plik

Każde wydanie ma plik SHA256SUMS.txt obok swoich plików. W folderze pobranego pliku uruchom:

shasum -a 256 -c SHA256SUMS.txt --ignore-missing
sha256sum -c SHA256SUMS.txt --ignore-missing

Aktualizacje

Aplikacja sprawdza aktualizacje i instaluje je przy restarcie: instalator w Windows, AppImage w Linuksie i pakiet .zip na macOS. Wersje .deb, .rpm i przenośną aktualizujesz, instalując nową wersję.

Wymagania systemowe

macOS
macOS 12 lub nowszy, Apple Silicon lub Intel.
Windows
Windows 10 lub 11, x64 lub ARM64.
Linux
x64, jako AppImage, pakiet .deb lub .rpm.
git
git w Twoim PATH.
Agent
Przynajmniej jeden agent programujący, na przykład npm install -g @anthropic-ai/claude-code.
Bez Node.js
Bez osobnego Node.js: aplikacja uruchamia narzędzia pomocnicze we własnym środowisku uruchomieniowym.
ssh
OpenSSH tylko wtedy, gdy uruchamiasz agentów na zdalnych maszynach.
